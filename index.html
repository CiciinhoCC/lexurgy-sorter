How to use it

Straight up just paste your lexurgy code on the input and press the button. It should return a better sorted version of all your phonemes.

Lexurgy definitions should be in the "Feature manner(nasal,plosive,fricative...)" and "Symbol p [labial plosive]" form. It won't do anything to other stuff.

It'll sort it by order of feature definitions. So it'll prioritize "type" over "manner" over "poa" in this example.

Limitations

It can sort diacritics too but I'm not sure if it does it proper.

I think it's fine to just paste all your lexurgy code in this, but if it isn't working then paste only the actual definitions.

It organizes the symbol matrix in the same order as how it's all defined, so instead of [voiced alveolar lat approx], l is instead [alveolar approx voiced lat], which doesn't sound natural.
